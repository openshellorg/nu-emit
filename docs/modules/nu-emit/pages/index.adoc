= nu-emit
:description: Emit structured rows for Nushell without hand-writing JSON.
:page-audience: developers integrating C or other native apps with Nushell

`nu-emit` is a small library (C first) that builds structured rows in memory and prints them as JSONL for Nushell (`from json`) so apps do not hand-roll escaped JSON strings.
Outbound structure only; plugin IPC is a later tier.

== Why

Nushell is happy if you print JSONL and pipe through `from json`.
That still means every C programmer reinvents `fprintf(stdout, "{\"pid\": %d...}")` and gets the commas wrong at 2am.

`nu-emit` is the boring fix: build a row in memory, call an API, flush.
First target is *C*.
Other languages can follow the same shape.

This is the "DevX approved" path from the Nu-vs-pwsh discussion: a real emit API, not folklore.
